
# NeuroGen AI Assistant 🤖

An interactive AI chatbot developed using Python,
Google Gemini API, and Gradio.

## Features

- Real-time AI responses
- Gemini API integration
- Conversation history
- Interactive chatbot interface
- Submit and Clear Conversation buttons
- Custom UI styling

## Technologies

- Python
- Google Gemini API
- Gradio
- HTML
- CSS

## Development Environment

Google Colab

## Deployment

GitHub and Render
